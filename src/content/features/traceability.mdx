## Traceability That Passes Audit
Not a separate module. Not a "quality add-on." Traceability is the natural byproduct of running production on Kaarya. Every cycle, every inspection, every downtime reason — linked automatically.

### What's Traced (Automatically)
| Level | Data Captured | Source |
|-------|---------------|--------|
| **Machine** | CNC/PLC ID, firmware, calibration cert | IoT Gateway |
| **Operator** | Badge ID, shift, certification, language | Mobile App / Shift Login |
| **Tool** | Tool ID, offset, wear compensation, life counter | PLC / Manual entry |
| **Material Lot** | PO, heat/lot number, CoA, supplier | Barcode scan / ERP sync |
| **Cycle** | Actual cycle time, spindle speed, feed, load, temp | PLC (500ms) |
| **Inspection** | Dimension, result, gauge ID, GR&R status | Manual / CMM import |

### Query Patterns (Sub-50ms)
- **Forward**: "Where did Lot #A442 go?" → All machines, operators, serial numbers, shipments
- **Backward**: "What went into Serial #SN-7788?" → Full genealogy tree → PDF in 1 click
- **Containment**: "Which parts used Tool T-12 after 10,000 cycles?" → Affected serials + customers
- **Audit**: "Show IATF 8.5.1.1 evidence for Customer X audit" → Pre-filtered genealogy pack

### Standards Mapping
| Standard | Clause | Kaarya Evidence |
|----------|--------|-----------------|
| **IATF 16949** | 8.5.1.1 | Complete genealogy per lot/serial |
| **AS9100** | 8.5.2 | FAIR genealogy (Forms 1/2/3) |
| **ISO 13485** | 8.2.6 | DHR per UDI-DI |
| **FDA 21 CFR 820** | 180 | DHR + e-signature ready |
| **CMMC** | 3.12 | Audit trail + access control |

### Air-Gap Native
Full genealogy queries run on local SQLite/PostgreSQL. Export → Print → Hand to auditor. Zero cloud.
