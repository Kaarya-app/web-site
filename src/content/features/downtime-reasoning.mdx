## Downtime Data You Can Trust
Most MES: "Other" selected 80% of the time. Operators hate it. Kaarya: Operators *use* it.

### Why Operators Actually Use Kaarya
| Barrier | Kaarya Solution |
|---------|-----------------|
| **Language** | 8 languages: English, Hindi, Tamil, Telugu, Kannada, Marathi, Gujarati, Bengali |
| **Gloved hands** | Voice input — speak reason, auto-categorized |
| **Too many clicks** | 3 taps max: Stop → Reason → Resume |
| **Don't know codes** | Visual icons + search + "Recent" row |
| **Forget to log** | Mandatory gate: Cannot tap "Resume" without reason |

### Pre-Loaded Reason Codes (35)
**Setup & Changeover**: Die Change, Tool Change, Fixture Change, First Article, Warm-up
**Material**: No Material, Wrong Material, Material Quality, Kit Shortage
**Quality**: Quality Hold, First Piece Inspection, Gauge Calibration, Rework
**Maintenance**: Breakdown, Preventive Maintenance, Tool Sharpening, Lubrication
**External**: Power Outage, Compressor Down, Crane/Forklift Wait, Supervisor Wait
**People**: Operator Break, Meeting, Training, Shift Handover
**Process**: Program Load, Parameter Adjust, Trial Run, Scrap Recovery

### Real-Time Pareto (Updates every 10 sec)
Live Pareto chart on TV + Mobile + Browser. Drill into any reason → see machines, shifts, trends. "Waiting for Inspection = 22%" found in 4 hours at Coimbatore job shop.
