## Industrial Reliability Without Database Administrators

Small and mid-sized machine shops rarely have database administrators to patch or maintain external database daemons. Kaarya embeds an industrial-grade SQLite engine directly into the core Go executable:

### High-Concurrency Industrial Tuning
- **Write-Ahead Logging (WAL Mode):** Decouples readers from writers so concurrent dashboard analytics queries never block high-frequency IoT telemetry writes.
- **In-Memory Page Cache:** Allocates 64MB of RAM to SQLite page caching plus 256MB memory-mapped I/O, ensuring active shifts, machine statuses, and cycle times stay in fast memory.
- **Dirty Shutdown Resilience:** `PRAGMA synchronous=NORMAL` guarantees database integrity against abrupt shopfloor power cuts without manual recovery.

### Zero-Downtime Hot Backups & Migration
- **Online Hot Backups:** Non-blocking backups via `VACUUM INTO` generate clean, atomic snapshots of the entire factory ledger without interrupting machine data streams.
- **Single-File Portability:** Complete production history is contained in a single file (`kaarya.db`), simplifying disaster recovery, USB drive archiving, and offsite copies.
- **Transparent PostgreSQL Path:** Built on an abstracted GORM persistence layer, enabling multi-node enterprise plants to switch to PostgreSQL simply by updating `config.json`.
