## Industrial Connectivity Inside a Single Binary (Beta)

> **Shopfloor Validation Notice (Beta):** The software protocol engines (Modbus TCP, OPC UA, MQTT Sparkplug B, HTTP edge ingestion) and the telemetry simulator are fully implemented and verified. We are currently actively conducting on-site shopfloor pilot tests on physical CNC mills, lathes, and PLCs. While hardware testing is in progress, all core software capabilities—including OEE calculation, downtime reasoning, shift handovers, and compliance records—are fully stable and production-ready.

Automated machine telemetry is the foundation of credible OEE and real-time Andon status. Kaarya eliminates complex external middleware stacks by embedding multi-protocol industrial adapters directly into the core binary:

### Native Protocol Adapters (ADR-0011)
- **Modbus TCP:** Polling cycles (configurable 100ms–10s) reading holding registers and coils via `goburrow/modbus`.
- **OPC UA:** Persistent binary sessions and monitored item subscriptions via `gopcua/opcua` for Siemens S7-1200/1500 and modern CNCs.
- **MQTT Sparkplug B:** Structured industrial MQTT payload decoding via `paho.mqtt.golang` across edge device namespaces.
- **Telemetry Simulator:** Built-in simulation adapter generating realistic cycle and status telemetry for demo and testing without physical machinery.

### Normalized Telemetry Pipeline
- Maps raw industrial tag addresses (e.g. `40001`, `ns=2;s=Line1.Speed`) to standard machine metrics (`status`, `speed_actual`, `part_count_good`, `scrap_count`).
- Automatically associates incoming machine cycle signals with active shifts, updating production counts and downtime intervals in real time.

### External Edge Gateway Integration (ADR-0012)
- For plants with pre-existing edge hardware (Node-RED on Revolution Pi, Ignition Edge on Opto 22), Kaarya provides a hardened HTTP endpoint:
```bash
curl -X POST https://your-kaarya-node/api/v1/iot/telemetry \
  -H "X-IoT-Token: <gateway-token>" \
  -H "Content-Type: application/json" \
  -d '{"machine_id":"CNC-01","metrics":{"status":"running","speed_actual":1250}}'
```
