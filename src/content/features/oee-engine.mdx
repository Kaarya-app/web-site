## Real-Time Equipment Effectiveness & Visual Trends

Kaarya's OEE engine computes the manufacturing gold standard live at machine speed and renders it through high-performance Apache ECharts:

- **Availability:** Actual Run Time / Planned Production Time (captures downtime & breakdowns)
- **Performance:** Total Parts / (Ideal Rate × Run Time) (captures speed loss, micro-stops)
- **Quality:** Good Parts / Total Parts (captures defect/scrap losses)
- **TEEP:** OEE against 24/7/365 calendar time (true capacity utilization)

### Interactive 60fps Visual Analytics
- **Multi-Line Bezier Splines:** Simultaneous visual decomposition of OEE (Cyan), Availability (Emerald), Performance (Amber), and Quality (Purple) with smooth gradient underlays.
- **Dynamic Time Ranges:** Instant toggles for `7D`, `1M`, `3M`, `6M`, `YTD`, `1Y`, and custom popover ranges triggering reactive backend recalculations.
- **World-Class Benchmark:** Integrated 85% World-Class OEE dashed target reference line and magnetic crosshair tooltips.
- **Micro-Sparklines & Machine Rankings:** Borderless trend splines inside primary KPI cards and color-graded machine performance ranking bars (`>85%` green, `70–85%` amber, `<70%` red).
- **Embedded WebKit & Air-Gap Optimized:** Canvas-based rendering runs smoothly at 60fps on shopfloor Linux panel PCs (WebKitGTK) with zero cloud round-trips.
