## Beta Pilot Status
This capability is actively deployed across select pilot customer shopfloors. It runs localized lightweight models directly on the edge node without requiring internet access or offsite cloud inference.

### What It Detects (Edge Models)
| Anomaly Type | Detection Method | Typical Lead Time |
|--------------|------------------|-------------------|
| **Micro-stops** (< 60 sec) | Isolation Forest on cycle time residuals | Real-time |
| **Sensor Drift** | Dynamic baseline regression on analog tags | Hours–Days |
| **Spindle Wear** | Vibration spectral analysis (if sensor available) | Days–Weeks |
| **Thermal Anomaly** | Multivariate correlation (temp + current + speed) | Hours |
| **Cycle Time Creep** | CUSUM control chart on part cycle times | Shifts |

### How It Works
1. **48-hour baseline**: Kaarya collects normal operation data (auto-starts on first run)
2. **Model training**: Lightweight Isolation Forest + regression models train on-edge (CPU only, < 2GB RAM)
3. **Live inference**: Every telemetry sample (500ms) scored in < 15ms
4. **Alerting**: Anomaly score > threshold → Andon Amber + Mobile push + optional email/Slack
5. **Root-cause assist**: Top contributing tags ranked (e.g., "Spindle Load +8%, Vibration X +12%")

### Air-Gap Native
Models train and infer 100% on the edge node. No model weights leave your VLAN. No cloud GPU needed. Runs on the same industrial PC as Kaarya Core.
