## The End of "Rajesh Knows"
Tribal knowledge lives in WhatsApp groups and operator memory. When Rajesh leaves, the knowledge leaves. Kaarya makes shift handover a structured, signed, searchable record.

### Outgoing Operator Logs (3 minutes)
| Section | Captured |
|---------|----------|
| **Production** | Actual vs target, good/scrap count, OEE % |
| **Downtime** | Top 3 reasons (auto from Pareto), total lost time |
| **Quality** | Open NCRs, gauge issues, first-article status |
| **Maintenance** | Open work orders, tool wear, PM due |
| **Tools** | Active tools, offsets, life remaining |
| **Notes** | Free text + voice → structured tags |

### Incoming Operator Signs Off
- Reviews pre-filled log (auto-populated from live data)
- Adds "Taking over" notes
- Digital signature + PIN
- Timestamped, immutable, searchable

### Auto-Generated Shift Report (PDF)
- **Header**: Shift, date, cell, operators (in/out), supervisor
- **KPIs**: OEE, Availability, Performance, Quality, Good/Scrap
- **Downtime Pareto**: Top 5 reasons with charts
- **Quality**: NCRs opened/closed, scrap by reason
- **Maintenance**: WO status, tool changes
- **Notes**: Both operators' notes, flagged items
- **Signatures**: Digital signatures with timestamps

### Pro/Enterprise Adds
- **Auto-Summary**: AI-generated executive summary for plant manager
- **KPI Comparison**: Shift vs Shift, Day vs Day, Week vs Week trends
- **Escalation Tracking**: Flagged items auto-assigned, tracked to closure
- **Multi-Cell Rollup**: Plant-wide shift report from cell reports
